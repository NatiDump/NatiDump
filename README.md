## Leaf Vein Background Pattern

Add a subtle, repeatable leaf-vein background similar to patisserie branding.

### Quick start

1. Include the CSS file:

```html
<link rel="stylesheet" href="styles/leaf-vein.css" />
```

2. Apply the class to any element (or `body`):

```html
<div class="bg-leaf-vein"> ... </div>
```

3. Customize via CSS variables:

```css
.bg-leaf-vein {
  --leaf-vein-size: 160px; /* scale of the motif */
  --leaf-vein-bg: #fffdf7; /* background fill color */
}
```

### Files

- `assets/leaf-vein.svg`: the tile artwork (200×200 viewBox)
- `styles/leaf-vein.css`: reusable class with embedded data-URI
- `demo/leaf-vein-demo.html`: preview with swatches

Open the demo file in a browser to see and tweak sizes/colors.
